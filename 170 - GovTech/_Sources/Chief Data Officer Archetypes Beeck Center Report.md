# Chief Data Officer Archetypes Beeck Center Report

## Summary

The Beeck Center at Georgetown identified six archetypes for state chief data officer roles, finding that no single model defines effective data leadership and that structure and resource allocation significantly shape outcomes.

## Key Points

The Beeck Center for Social Impact + Innovation at Georgetown University released a report mapping the landscape of chief data officer roles across state governments. Key findings:

There is no dominant CDO model. Six distinct archetypes were identified, varying along dimensions including reporting structure, mandate breadth, budget authority, and relationship to IT leadership.

Resource allocation matters as much as org chart placement. CDOs with limited budgets and no direct staff struggle to have influence regardless of where they sit in the hierarchy.

The report is a useful reference for thinking about how jurisdictions structure data governance functions and what makes those functions effective versus nominal.
