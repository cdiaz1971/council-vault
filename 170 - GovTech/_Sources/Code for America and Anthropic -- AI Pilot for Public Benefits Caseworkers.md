# Code for America and Anthropic -- AI Pilot for Public Benefits Caseworkers

## Summary

Code for America is partnering with Anthropic on a pilot intended to help government caseworkers more efficiently administer public benefits. The core use case is AI-powered policy navigation: making complex, frequently-changing policy information more accessible to the workers who must apply it daily, so they can focus on the human work of serving residents rather than searching through policy manuals.

## Key Points

The framing here is important: this is AI augmenting caseworkers, not replacing them. The goal is reducing the cognitive overhead of policy navigation so workers can spend more time on the human judgment and relationship work that AI cannot do. This is a model for thinking about AI in government service delivery that should inform how Frederick approaches similar questions.

Code for America has a track record of practical civic tech work, not just research. A partnership with Anthropic suggests they are building with current frontier models and treating this as a production pilot, not a demo.

Public benefits administration is a high-stakes domain: incorrect denials or delays have direct human consequences for vulnerable residents. AI tools in this space need to be accurate, auditable, and designed to support worker judgment rather than override it.

## Relevance

This is the kind of GovTech application worth tracking closely for Frederick. As the city considers how to use technology to improve service delivery, the Code for America model -- AI for policy navigation by workers, not AI replacing workers or making direct citizen-facing determinations -- is the right design philosophy.

See also the broader [[Municipal Technology Strategy]] gap note, which should eventually be written.
