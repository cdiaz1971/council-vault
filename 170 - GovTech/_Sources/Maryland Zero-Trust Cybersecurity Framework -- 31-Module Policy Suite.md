# Maryland Zero-Trust Cybersecurity Framework -- 31-Module Policy Suite

## Summary

Maryland's Department of Information Technology released a 31-module zero-trust cybersecurity policy suite in early March 2026, requiring all 22 Cabinet agencies to adopt it within 18 months. The framework replaces a 200-plus page document from 2019 and is designed to be a model other governments can adapt. Local governments including Frederick are not required to follow it but are encouraged to do so.

## Key Points

The core shift: from "trust but verify" to "never trust, always verify." Under the new framework, no device or user earns network access based solely on location. All users inside and outside an agency's network must be continuously authenticated, authorized, and validated before accessing applications and data. This is particularly enforced for "high value state systems."

The policy was developed with over 1,200 comments from state agencies, local governments, and cybersecurity experts. CISO James Saunders (who joined in 2025 mid-process) described the effort as a half-marathon, not a sprint -- cautioning against piling on additional changes before new ones settle.

Alongside the policy suite, Maryland has also:
- Consolidated disparate Active Directory domains across agencies
- Hired 15 information security officers statewide
- Launched a Vulnerability Disclosure Program (VDP) through Bugcrowd, letting researchers and residents legally report security flaws in public-facing systems
- Expanded the Maryland Information Sharing and Analysis Center
- Added a statewide vulnerability disclosure program

The VDP covers executive branch offices, local governments, commissions, and organizations on networkMaryland -- the state's fiber-optic backbone connecting 137 public-sector entities. Remediation is collaborative rather than punitive.

## Why This Matters for César

As Frederick's M365/Azure Administrator, this framework is directly relevant. Maryland is not requiring local governments to adopt it, but it is a well-structured, publicly available model that Frederick could use as a baseline for its own cybersecurity governance. The zero-trust approach aligns with Microsoft's security architecture recommendations for M365 and Azure environments. The VDP model is also worth flagging -- Frederick could participate in networkMaryland's umbrella VDP rather than building its own.
