# Arizona Data Readiness Framework -- Structured Approach to Agency Data Maturity

Arizona Chief Data and Analytics Officer Josh Wagner has built what GovTech calls a "first-in-nation" framework for assessing data quality and maturity across state agencies. The model evaluates readiness across agencies before deploying data-driven or AI-powered services -- addressing the foundational problem that most government AI failures trace back to poor underlying data rather than model quality.

The framework is designed to surface where agency data is unreliable, inconsistently structured, or insufficiently documented before those problems propagate into AI outputs or data-sharing agreements.

## Why this matters for César

This is a practical model for the municipal technology strategy track. Before Frederick deploys any AI-assisted services -- permitting, constituent communication, code enforcement -- understanding data quality and maturity is the prerequisite. The Arizona framework provides a reference architecture for what that readiness assessment looks like.
