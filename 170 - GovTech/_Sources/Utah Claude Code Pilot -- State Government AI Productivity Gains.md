# Utah Claude Code Pilot -- State Government AI Productivity Gains

## Summary

Utah's Director of AI Christian Napier reports that piloting Claude Code at state agencies saved 40 hours of developer work over a four-week period, representing a concrete early data point for AI productivity in state government.

## Key Points

Utah's AI pilot using Claude Code at state agencies produced a measurable result: 40 hours of developer time saved over four weeks. The pilot was described by Utah's Director of AI as an inflection point -- an AI "magic moment" that accelerated IT development velocity.

This is notable because it is a specific, quantifiable outcome from a state government context rather than a vendor claim. It represents one of the first documented productivity numbers from a sub-federal government AI coding deployment.

The GovTech coverage situates this alongside Washington State CIO Bill Kehoe discussing how AI can ease legacy system modernization, and Pennsylvania CISO Andy Ritter emphasizing outcome-driven security posture. The through-line is that state-level IT leaders are beginning to operationalize AI in ways that produce measurable results.

## Relevance

As M365/Azure administrator, this is directly relevant to the case for AI tooling in city government. The Utah number -- 40 developer hours in four weeks -- is the kind of concrete return-on-investment data point that supports a Copilot or AI coding deployment pitch to leadership.
