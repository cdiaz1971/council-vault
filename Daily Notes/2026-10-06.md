## Coming Up (next 7 days)

```dataview
TABLE WITHOUT ID choice(length(filter(rows, (r) => contains(r.file.name, " Brief "))) > 0, filter(rows, (r) => contains(r.file.name, " Brief "))[0].file.link, rows[0].file.link) AS "Meeting", rows[0].mdate AS "Date"
FROM "180 - Meetings"
WHERE regextest("^.+ (Agenda|Brief) \d{4}-\d{2}-\d{2}$", file.name)
FLATTEN date(regexreplace(file.name, "^.*(\d{4}-\d{2}-\d{2})$", "$1")) AS mdate
WHERE mdate >= date(this.file.name) AND mdate <= date(this.file.name) + dur(7 days)
GROUP BY regexreplace(file.name, " (Agenda|Brief) ", " ") AS meeting
SORT rows[0].mdate ASC
```

## Created Today

```dataview
TABLE WITHOUT ID file.link AS "Note", file.folder AS "Folder"
WHERE file.cday = date(this.file.name)
  AND file.path != this.file.path
  AND !startswith(file.folder, "Templates")
  AND !startswith(file.folder, "Daily Notes")
SORT file.ctime ASC
```
