# Michigan Data Center Land Use Restriction -- 1500 Square Miles Off Limits

## Summary

Michigan moved to restrict 1,500 square miles of the state from data center development, a significant state-level intervention that removes the vulnerability of local moratorium politics by preempting it from above.

## Key Points

Michigan enacted a state-level land use restriction prohibiting data center development across roughly 1,500 square miles. The specific rationale and implementation mechanism were not detailed in the GovTech brief, but the scope is substantial -- this is not a local moratorium but a broad geographic exclusion at the state level.

This represents a different policy tool than the local community benefit agreement or permitting condition approach: instead of shaping how data centers operate in a jurisdiction, it eliminates the option entirely in designated areas. The instrument appears to be a land classification or zoning preemption at the state level.

Contrast with Charlotte, where a local moratorium was defeated by a mayoral vote, demonstrating that local moratoriums are politically fragile. State-level restrictions bypass that fragility entirely.

## Relevance

Maryland does not currently have a comparable state-level restriction, which means Frederick's data center policy remains a local fight. The Michigan precedent is worth tracking as a model for Maryland advocacy -- if the state were to act, it would relieve local councils of having to fight this individually. Worth flagging to Progressive Maryland contacts. See also [[Charlotte Data Center Moratorium -- Mayor Casts Deciding Vote Against]] for the contrasting local fragility case.
