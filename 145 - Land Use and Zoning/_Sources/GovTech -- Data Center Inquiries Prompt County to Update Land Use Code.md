# GovTech -- Data Center Inquiries Prompt County to Update Land Use Code

## Summary

A GovTech Today brief noted that a county government updated its land use code in direct response to an influx of data center development inquiries. The item validates the approach other jurisdictions are taking: using land use code updates as the primary regulatory tool for managing data center siting.

## Key Points

- A county (unnamed in the newsletter headline) updated its land use code after receiving significant data center inquiries from developers
- The update is reactive -- triggered by inquiry volume, not proactive policy
- Pattern matches what Frederick is navigating with the [[LMC Review]] and [[Data Center Policy]]

## Relevance

Direct precedent for Frederick's situation. If a county is updating land use codes in response to data center inquiry pressure, Frederick is not alone -- this is becoming a standard local government response pattern. Useful framing for council discussions: Frederick has an opportunity to be proactive rather than reactive, which generally produces better policy outcomes. Also connects to [[Sanders and AOC Propose Federal Data Center Moratorium]] -- the federal conversation and local land use updates are happening simultaneously, which may create a window for stronger local conditions before federal preemption becomes a risk.
