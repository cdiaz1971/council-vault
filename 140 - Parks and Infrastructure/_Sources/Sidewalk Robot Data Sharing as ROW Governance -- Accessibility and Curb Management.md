# Sidewalk Robot Data Sharing as ROW Governance -- Accessibility and Curb Management

## Summary

Sidewalk delivery robots generate granular real-time data on sidewalk conditions -- curb ramp gaps, ADA hazards, obstructions -- as a byproduct of navigation. Robot.com captured 35,000 ADA hazard data points in DC in 2024. Cities requiring Mobility Data Specification (MDS) data sharing from operators are building a sidewalk intelligence layer that, if actually used, could transform how municipalities prioritize accessibility capital spending.

## Key Points

The gap between data collection and data use is the story. Cities are requiring MDS data sharing. The data is coming in. But so far, almost no city is systematically using robot-generated sidewalk condition data to drive repair prioritization. The exception was a Coco-identified curb ramp gap on Abbot Kinney Boulevard in Venice, LA -- three missing ramps that turned blocks into "islands" for wheelchair users -- which Coco flagged to the council district office and the city repaired. That's still a manual, relationship-dependent process rather than a systematic pipeline.

The future model being explored: robots as continuous monitoring infrastructure, flagging issues to city systems automatically, enabling data-driven capital prioritization rather than complaint-driven reactive repair. Helsinki is running a Coco-Swarco partnership that lets robots adjust traffic light timing for pedestrian volumes -- a real-time physical-digital integration model.

Robot.com co-founder David Rodriguez articulated a clear ADA principle: if a sidewalk is too narrow for a robot to pass a wheelchair user, robots shouldn't be on that sidewalk. That's a useful standard for any Frederick ROW permitting framework -- operator self-exclusion from inaccessible sidewalks as a licensing condition.

Data shared by operators is described as fully anonymized. The privacy question is less about individual tracking and more about whether robot sensor data (cameras, environmental sensors) creates secondary surveillance infrastructure -- a question cities haven't answered yet.

## Relevance

The data-sharing model is the more durable policy lever than the fee model. If Frederick ever permits delivery robots or other commercial ROW users with sensor capability, requiring structured accessibility data reporting as a license condition costs operators almost nothing while giving the city infrastructure intelligence it currently pays for through expensive manual surveys.

This connects to the broader municipal tech consent and data governance framework already in the vault. The principle: any entity operating commercial technology in public rights-of-way should be contributing structured data back to the city as a condition of that access, not just paying fees.
