# Applying Residential Building Codes to Small Multifamily (Dallas Model)

Dallas revised its building code to apply the lighter International Residential Code — rather than commercial standards — to buildings up to 8 units and 3 stories, eliminating sprinkler requirements and significantly reducing costs for small multifamily development.

**Key implication for Frederick:** Frederick may have the same code mismatch constraining missing middle production. Worth querying the city's building official on whether 2-8 unit buildings are currently subject to commercial code requirements, and what a Dallas-style fix would require.
