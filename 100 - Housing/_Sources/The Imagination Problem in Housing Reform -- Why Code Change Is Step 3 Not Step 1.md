# The Imagination Problem in Housing Reform -- Why Code Change Is Step 3 Not Step 1

## Summary

Synthesis across four sources showing that housing reform fails not because the code isn't changed but because cultural imagination, political will, and design capacity must precede and follow legal change -- and that demonstration, not argument, is the mechanism for building all three.

## The Pattern

Four recent sources converge on a single underlying problem, each naming it differently:

- **Lubeck** calls it a sequential hierarchy: cultural discontent must precede political will, which must precede legal reform, which must precede design capacity, which must precede great development. Skip steps and the whole thing stalls.
- **Wesolowski (Happy Urbanist)** calls it the Backrooms problem: suburbia cannot meaningfully change because it was built all at once and codified into policy. Most residents have no reference point outside what they've always known. You can't argue someone into imagining what they've never experienced.
- **The Happy Urbanist's earlier piece** calls it the imagination barrier: logical arguments don't breach the gap between someone's current model of what's possible and the future you're proposing. Only experience can.
- **Better Block** calls it the market demand problem: officials and developers see no demand for walkable, human-scale development because no one has demonstrated it. Temporary activations replace speculation with evidence.

Same problem. Different vocabularies.

## What It Means for Housing Reform

The implication is not that code change is unimportant -- it is essential. But it is a middle step, not the beginning or the end.

**Before code change:** Cultural imagination has to shift. Residents have to be able to picture the alternative before they can stop opposing it. This is why public hearings dominated by opponents are a poor signal -- most people who would benefit haven't had the experience that would put them in the room.

**During code change:** Political will requires that elected officials believe their constituents want something different and that something better is actually possible. That belief comes from having seen it work somewhere. Peer city evidence, Better Block activations, and the "show don't tell" methodology are not supplementary to the political process -- they are upstream of it.

**After code change:** Legal freedom doesn't automatically produce great development because the design capacity has to be there. Lubeck's point is sharp: if it's been illegal for 40 years, schools and trades haven't taught it. The code change enables the learning, it doesn't create it. We are at least a decade away from having a deep bench of designers and builders who are fluent in human-scale urbanism at the scale we need.

## The Mechanism: Demonstration, Not Argument

All four sources point to the same lever: shared experience.
21st
- You cannot argue someone past the imagination barrier; you can take them to a street fair on a temporarily closed street and let their body make the argument
- Better Block's data shows that a $50,000 pop-up activation routinely unlocks millions in city investment -- because the demonstration converts skeptics at the institutional level, not just the residential level
- Wesolowski's deeper point is that suburban residents aren't enemies -- they're future supporters who haven't yet had the experience that would move them. The horizon is long but not fixed.

## Frederick Implications

Frederick's LMC Reform Commission and Housing Production Target work sit squarely in this pattern. The code work is genuinely essential -- without it, nothing can be built differently. But the political conditions for the code to be passed, and the community conditions for the code to produce what it enables, both require the demonstration track to be running in parallel.

Concrete applications:

1. **Pair every code change conversation with a demonstration.** Don't just describe what a mixed-use corridor could look like in East Frederick or along the Golden Mile -- build a temporary version of it and let people walk through it before the vote.

2. **Use Better Block methodology for contested nodes.** The three case studies (Tallahassee, Corpus Christi, Dallas) show consistent results: $5K–$50K activation, millions in follow-on public investment, belief converted.

3. **Don't expect one good public meeting to move opposition.** The imagination barrier means that the people in the room opposing density are often doing so in good faith from within a mental model that has never been breached. The intervention is experiential, not argumentative.

4. **Think about design capacity as a 10-year problem.** Code reform unlocks the legal right to build differently. But the architects, developers, and tradespeople who know how to execute human-scale urbanism at volume don't exist yet in Frederick in the numbers needed. This is a long game.

## What This Synthesis Adds

Any of these four notes in isolation is useful. Together they name something none of them quite says alone: the policy track and the imagination track have to run simultaneously, and the imagination track is actually upstream. The failure mode for reform is treating code change as the whole project and being surprised when the community still can't see what you're trying to build -- and when designers don't know how to build it even if they wanted to.

This is also why César's own role as Council President matters beyond votes. The visible, public advocacy -- the demonstrations, the trips, the stories of what works elsewhere -- is not supplementary to governance. It's the precondition for the governance to work.
